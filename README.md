## Запуск
```bash
go run ./cmd/node/main.go
```
### Флаги:
* `-name` - имя пользователя (если не указывать, то генерится само)
* `-port` - порт (по умолчанию: 8080)
* `-storage` - путь до папки, сохранение

## Команды:
* `/chat [nick-name]` или `/chat group:[chat-id]` - переключиться в личный или групповой чат
* `/new` - показать только чаты с непрочитанными сообщениями
* `/all` - показать все чаты и счетчик непрочитанных
* `/create -name [group name] -parts [nick1, nick2, ...]` - создать групповой чат
* `/announce [путь до файла] [id файла]` - анонсировать файл (id можно не укзывать, генерится сам)
* `/download [id файла]` - скачать файл по id

## Хранение истории
История чатов и сообщений хранится в одной SQLite базе данных.
Для SQLite используется драйвер `modernc.org/sqlite` (без CGO).
